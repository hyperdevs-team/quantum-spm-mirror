# Quantum Metric Fastlane dSYM Upload

Upload iOS dSYM symbolication files to Quantum Metric for crash reporting.

## Two Integration Options

### Option 1: Fastlane Plugin (Recommended)

Install the gem and use it like any fastlane plugin.

See [`fastlane-plugin-quantum_metric/README.md`](fastlane-plugin-quantum_metric/README.md)

### Option 2: Standalone Action

Drop a single Ruby file into your `fastlane/actions/` directory. No gem installation required.

See [`standalone/README.md`](standalone/README.md)
